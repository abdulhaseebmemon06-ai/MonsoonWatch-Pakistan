A Data Science Project for Pakistan

Understanding Rainfall.
Exploring Patterns.

MonsoonWatch Pakistan is a machine learning-based rainfall analysis and forecasting platform developed to explore historical weather patterns across Pakistan. It combines historical weather data, data analysis, and machine learning to generate rainfall estimates and provide meaningful insights through an interactive web application.

DATA SCIENCE MACHINE LEARNING PAKISTAN WEATHER DATA
01 / PROJECT INTRODUCTION

What is MonsoonWatch Pakistan?

Bringing historical weather data and machine learning together in one interactive platform.

Our Project

Rainfall is an important part of Pakistan's climate, particularly during the monsoon season. Understanding how rainfall changes over time can help researchers and students explore weather patterns and seasonal variations.

MonsoonWatch Pakistan was developed as a Data Science project to study these patterns using historical daily weather observations. The project follows a complete machine learning workflow, from dataset preparation and exploratory analysis to model training, evaluation, and web application development.

The platform provides historical visualizations, rainfall prediction functionality, model evaluation results, and information about the underlying dataset and methodology.

⌁

Our Core Idea

Transform historical weather observations into understandable information and explore how machine learning can be applied to rainfall estimation in Pakistan.

06 / MACHINE LEARNING

The Prediction Engine

A supervised machine learning regression approach for rainfall estimation.

Random Forest Regressor – V2

Ensemble-based supervised learning model

MODEL V2
Random Forest is an ensemble learning algorithm that combines predictions from multiple decision trees. In this project, it is used as a regression model to estimate rainfall amounts. The trained model is saved and integrated into the application for prediction requests.
Mean Absolute Error 1.8871 mm
Root Mean Squared Error 8.6384 mm
R² Score 0.1161
Performance note: These metrics come from the historical test dataset. The model performs better than the Mean Baseline on the overall evaluation metrics, but its R² score is modest and it significantly underestimates heavy rainfall. It requires further improvement.

10 / TRANSPARENCY

Limitations & Responsible Use

Understanding what the current version can and cannot do is an important part of this project.

⚠

Not a flood classifier: The model estimates rainfall amounts. It does not identify or predict verified flood events.

⚠

No live weather connection: The current application does not automatically retrieve live weather observations.

⚠

Heavy rainfall limitation: The current model significantly underestimates heavy rainfall events.

⚠

Geographical coverage: The dataset contains 22 coordinate-based locations, not complete coverage of every district in Pakistan.

⚠

Historical data: The dataset currently ends on 30 June 2026.

⚠

Research application: Results are intended for educational analysis and experimentation, not official weather warnings.

11 / LOOKING AHEAD

Where Can MonsoonWatch Go Next?

The current version establishes a foundation for historical rainfall analysis and machine learning experimentation. Future development could focus on improving extreme-rainfall predictions, expanding geographical coverage, and integrating additional weather data sources.
